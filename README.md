This repository contains the formalization and implementation developed as part of my master's dissertation on the LF logical framework. It is organized into two directories:

-  **`Idris/`** - Contains the formalization of propositional, first-order, second-order, and higher-order logic, focusing on establishing the validity of logical formulas.

- **`Lf/`** - Contains the formalization of propositional, first-order, and higher-order logic, and formal proofs of metatheoretical properties regarding the encoded logics. It also includes a small example involving a monosequent lattice logic (LL).
