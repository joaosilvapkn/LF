# LF

The Edinburgh Logical Framework (LF), is a metalanguage designed for the specification of deductive systems, and provides a uniform setting to represent and reason about various logical theories.

## Meta

- **Author:** João Silva
- **Compatible Idris 1 versions:** 1.3.3 or later
- **Compatible Twelf versions:** 1.7.1 or later



## Repository Organization

This repository contains the formalization and implementation developed as part of my master's dissertation on the LF logical framework.

It is organized into two directories:

-  **`Idris/`** - Contains the formalization of propositional, first-order, second-order, and higher-order logic, focusing on establishing the validity of logical formulas.

- **`Twelf/`** - Contains the formalization of propositional, first-order, and higher-order logic, and formal proofs of metatheoretical properties regarding the encoded logics.
